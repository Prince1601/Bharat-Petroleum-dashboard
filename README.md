# Bharat-Petroleum-dashboard
📌 Project Overview

This project is a Power BI Dashboard developed to monitor the health and uptime of automation devices deployed across Bharat Petroleum Corporation Limited (BPCL) Retail Outlets (ROs). The dashboard provides real-time insights into the operational status of MPDs (Multi Product Dispensers) and Tank Automation Systems, helping identify outlets facing technical issues and enabling faster troubleshooting and decision-making.

The primary objective of this dashboard is to improve visibility into automation infrastructure performance by tracking device uptime, online/offline status, vendor distribution, and configuration mismatches across retail outlets.

🎯 Business Problem

Managing automation devices across hundreds of retail outlets can be challenging. Device downtime can impact fuel dispensing operations, inventory monitoring, and data reporting.

This dashboard helps answer key operational questions:

How many Retail Outlets (ROs) are currently online?
How many MPDs and Tanks are operational?
Which outlets are experiencing automation device failures?
What is the uptime percentage of MPDs and Tank Monitoring Systems?
Are there any MPD configuration mismatches causing operational issues?
Which automation vendor has the highest deployment footprint?

📈 Key Metrics Tracked
Metric	Description
Tank Uptime %	Overall uptime percentage of tank automation systems
MPD Uptime %	Overall uptime percentage of fuel dispensers
Online MPDs	Number of MPDs currently communicating
Online Tanks	Number of tank systems currently communicating
On-boarded MPDs	Total registered MPDs
On-boarded Tanks	Total registered tank systems
Vendor Distribution	Automation vendor deployment analysis
Configuration Mismatch	Identification of MPD configuration discrepancies
